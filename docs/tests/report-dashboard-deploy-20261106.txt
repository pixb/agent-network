## 追加（同日）：已上线提交的 commit 信息改英文 —— 1f92fae → 9d868e113

用户要求：`pixb` 上那个已上线提交的 commit 信息从中文改成英文。
改信息会**换 SHA**，而当时运行镜像的 label 就是 `1f92fae`。
所以这不是「改个文案」，而是一次**必须成对做**的操作：

    ① docker tag anet-dashboard:compose anet-dashboard:rollback-20261106b   # = 01e68aad2e5b（先打，否则无法回滚）
    ② git commit --amend（英文信息）→ 9d868e113dadf722b8ba5ea39e94ed1ea9e7b656
       git diff --stat 1f92fae 9d868e113   → 空（**同一棵树**，只是信息换了）
       git show --stat --format="" HEAD    → 9 files, +381/-75
    ③ git push --force-with-lease origin pixb
    ④ docker build -f deploy/compose/Dockerfile.source --build-arg SOURCE_REV=9d868e113… --build-arg SOURCE_DIRTY=false -t anet-dashboard:compose .
    ⑤ docker compose up -d --no-build dashboard

为什么 ④⑤ 不可省：③ 之后 `1f92fae` **不再在 pixb 历史里**
（`git merge-base --is-ancestor 1f92fae origin/pixb` 判否）。若此时不重建，
现网 label 就变成一个分支里查不到的提交 —— 正是 hub 那次抓到的反例
（label `34cbb9a4` 不在 pixb 历史里，于是无法回答「跑的是哪份代码」）。
