## 换镜像序列（照 README §9）

1. 先给现网镜像打回滚 tag（不先打就没法回滚）：
       anet-dashboard:rollback-20261106 -> 170f1df5e74d (1.65GB, 2026-11-04 那版)
2. 源码构建，label 传刚推送的提交：
       docker build -f deploy/compose/Dockerfile.source --build-arg SOURCE_REV=1f92fae... -t anet-dashboard:compose .
       → 新镜像 01e68aad2e5b, 1.65GB
3. `docker compose up -d --no-build dashboard`
   🔴 `--no-build` 是硬要求：父 compose 的 build.dockerfile 指 npm 钉版定义
   （Dockerfile.dashboard，ARG DASH_VERSION=0.6.3-preview.56），
   不带 --no-build 的 plain `up` 会用 npm 的 preview.56 覆盖掉 pixb 源码镜像。
