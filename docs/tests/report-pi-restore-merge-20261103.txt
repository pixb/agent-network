== 已知缺口（未修）==
A. tests/test-pi-compile-check 在本机跑不起来（本机问题，非代码问题）:
   - Dockerfile 写死 registry.npmmirror.com，本机不可达 → bun install 挂起
   - RUN 里 `bun add -g typescript` 以 /check 为 cwd，会生成 /check/package.json
     + bun.lock，把 /check 变成 bun workspace 根，使随后的子包 install 直接 exit 1
   本次以本地等价命令（第 5-8 项）覆盖同一道门。
B. npm 上所有 agent-node 版本（实测 .147/.148/.154/.159/.165/.175）都不含 pi 运行时，
   本地 tgz 只有 .154/.158/.159 有。合并后的 pair 指向 2.5.0-preview.175 →
   `anet node start --runtime pi-cli` 会被 candidate 守卫拒
   （"the candidate agent-node does not advertise pi-cli"）。
   要跑起来必须从 pixb 构建并发布/安装带 pi 的 agent-node，再 bump pair。
C. 旧 pixb-backup 上的 docs 测试报告、.191/.154 发布准备、skill 子模块指针
   未恢复（判定为历史产物，非日常代码）。
