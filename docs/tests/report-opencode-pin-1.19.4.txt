opencode V1 pin bump: 1.19.3 → 1.19.4
版本: 2.3.0-preview.194 / 2.5.0-preview.157（成对 tgz，不发 npm）
分支: pixb

一、变更
  将 opencode V1（npm `opencode-ai`）的精确锁定版本从 1.19.3 升到 1.19.4。
  受影响的三个源文件（双份镜像）：
    agent-node/src/runtime/opencode-versions.ts
    agent-network/src/opencode-versions.ts
    agent-network/src/opencode-pin.ts （OPENCODE_DEFAULT_PIN 派生）

二、迁移窗口（RFC-029 Board #541）
  acceptedVersions 顺序：新 pin 在前，旧 pin 退为 transition window 第二位：
    ["1.19.4", "1.19.3", "1.19.0", "1.18.35", "1.18.34", "1.18.1"]
  仍保留的 transition 版本：1.19.3、1.19.0、1.18.35、1.18.34、1.18.1
  —— 仍持有这些 exact 版本的机器能正常起动，并在启动时收到升级提示；
    其他版本（如 1.19.1/1.19.2/1.18.2/2.0.22 等）直接拒绝。

三、测试同步
  · agent-network: opencode-pin.test.ts、opencode-package-binary.test.ts 同步期望值
    （transition window 从旧 pin 1.19.0 变为新旧 pin 1.19.3、1.19.0…）；
  · agent-node: opencode-acp/binary.test.ts 同理更新 transition window 期望值；
  · 双份 opencode-versions.ts 字节级一致性由 opencode-versions-parity.test.ts 守门。
